# Picowizard Infrastructure
This is software infrastructure for using the [Picowizard 8 bit RISC ISA by RascalFoxfire.](https://github.com/RascalFoxfire/Picowizard)

This project currently includes:
 - The Assembler (picowizard-asm)
 - The Emulator  (picowizard-emu)


Currently Supported ISA Versions:
 - 1.2
 - 1.2 Plus
